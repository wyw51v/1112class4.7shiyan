# 数字人文 4.7 · 主题探索与作者文本对比

《数据科学与数字人文》第 4 章「任务 4.7：综合实践」的完整实现：以《全唐诗》中李白、杜甫各 25 首八句律诗为语料，完成**主题探索（TF-IDF + LDA）**与**两位作者文本特征对比**两项任务，并保留全部中间结果与可复现配置。

> 语料 50 篇（任务一上限）· 全部八句律诗（五言 38 / 七言 12）· 单篇 39–56 字 · 固定随机种子 42

## 三、复现

```bash
# 1) 建隔离环境（不入库，约 190 MB）
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt    # macOS/Linux 用 .venv/bin/python

# 2) 一键跑完：分词 → 主题 → 作者对比 → 抽查表 → 报告
.venv/Scripts/python.exe src/run_all.py

# 3) 附加实验：jieba 分词 vs 字级切分的对比
.venv/Scripts/python.exe src/seg_compare.py
```

重跑会覆盖 `outputs/` 与 `deliverables/00_交付报告.md`，其余四份文档为人工撰写，不受影响。仓库已托管 `corpus.jsonl`，**不需要联网**；只有重建语料时才需下载《全唐诗》分片。

## 四、两处方法判断（也是本作业的主要发现）

1. **jieba 不适用于古诗词**。实测在 50 首唐诗上切出 1020 个词，其中 **93.0% 只出现一次**（「疑是」「明月光」这类临时组合），跨作者比较失去意义；改字级切分后一次词占比降到 62.1%。故 `config.json` 取 `tokenizer: "char"`，理由与实测表写入 [`01_语料说明卡.md`](deliverables/01_语料说明卡.md)。若换现代诗文或报刊语料，改回 `"jieba"` 并把 `min_token_len` 设为 2。
2. **本语料不支持稳定的主题结构，因此没有强行报告主题**。k=3–6 的跨随机种子稳定性仅 0.079–0.120，换种子主题词即变。报告据此改为**以 TF-IDF 为主证据、LDA 仅作交叉印证**，并明写「本语料不足以支撑主题建模」。这对应教材 4.6 节「语料偏见与客观幻象」，比凑出三个不可复现的主题更符合规范。

## 六、换成自己的语料

1. **改语料**：编辑 `corpus/corpus.jsonl`，一行一篇（除 `text` 外都可留空）：

```json
{"id":"doc_001","author":"作者甲","title":"篇名","year":"1934","genre":"杂文",
 "source":"《申报》1934-05-01","license":"已获授权","text":"正文……"}
```

2. **改参数**：`config.json`
   - `tokenizer`：`"jieba"`（现代诗文、报刊、档案）或 `"char"`（古诗词）
   - `min_token_len`：现代汉语设 2，古汉语设 1
   - `lda.k_list`：语料变大后可扩到 5–15
3. **重跑**：`python src/run_all.py`，再打开 `outputs/原文抽查表.csv` 做人工核查。

> 脚本开头会自动体检篇数：任务一需 10–50 篇同源文本，任务二两位作者各 ≥10 篇，不合规会警告。

## 七、数据来源与许可

- **语料**：唐诗原文取自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 整理的《全唐诗》公开数据集（繁转简后使用）。唐诗原文属**公有领域**；数据集本身以 MIT 协议发布，此处仅引用其文本整理成果。
- **代码**：本项目代码可自由参考、修改。
- **字体**：图表中文使用系统字体（Windows 微软雅黑 / macOS PingFang），仓库不含字体文件；他机重跑时若中文显示为方块，改 `src/common.py` 的 `FONT_PATH` 即可。

## 八、脚本自动完成 vs 必须人工完成

**脚本完成**：分词与停用词、语料统计、TF-IDF 关键词、LDA 多 k 与双种子稳定性、作者关键词与倾向词、两张图、40 条抽查记录（关键词→原句→出处）、分析摘要、交付报告。

**必须人工完成**（也是量规里的得分点）：
1. `outputs/原文抽查表.csv` 最后一列「语境是否支持该关键词」逐条判断——占 25%，只能由读过原文的人填；
2. `outputs/LDA_主题词.csv` 的「人工主题标签」列，按高权重词与抽查结果自行命名；
3. 150 字解释改定为自己的话；
4. 两篇方法参照文献的读后比较：写「各自回答什么问题」，不要写成「哪个方法更好」。
